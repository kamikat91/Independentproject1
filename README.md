# Idependantproject1

This project is a text-based adventure game where the player selects certain chocices that impact the outcome of the story
HOW TO PLAY:
        -boot up the game and go through the story at certain moments you will be presented with a different number of choices
        -to select one of these choices you will enter a number/integer through an input
ITEM SYSTEM:
          -The item system is in develpment and currently does not have a use so far in game
          -The Item system is planned to be used to unlock certain choices that can change the story
          -Item can carry weight so your storage will have a weight limit to how much weight you can hold
          -Doing certain choices can give or take away items. This will be tracked through a class varible in the code
          -Every choice section that comes up will tell you what items you have and how much weight youre carrying
